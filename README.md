# Manual técnico de la plataforma LEEDUCA

Libro web (Quarto) con las fichas técnicas de las tareas de la plataforma LEEDUCA/PRELEO
(Universidad de Málaga): descripción, muestra, fiabilidad, validez, baremos y variables que influyen.

**Estado:** borrador de trabajo v0.1. Web: https://abarejo.github.io/leeduca-manual/

- Solo contiene **datos agregados** (`datos/agregados/`). Los datos individuales no salen del proyecto.
- Cómo se mantiene: ver el capítulo «Cómo se mantiene este libro» (`colaborar.qmd`).
- Generar en local: `quarto render` (necesita R con `ggplot2`, `knitr` y `rmarkdown`).
